# 🎧 RANKUP

**Avalie. Ranqueie. Descubra.**

O RANKUP é uma plataforma para amantes da música avaliarem, ranquearem e descobrirem álbuns. Inspirado em plataformas como o Letterboxd, o projeto traz para o universo musical uma experiência baseada em avaliações, rankings e descobertas.

> 🚧 **Status:** em desenvolvimento (fase inicial)

---

## 🎯 Objetivo

Transformar o ato de ouvir música em uma experiência mais interativa e social:

**Ouvir → Avaliar → Ranquear → Descobrir**

Cada usuário constrói seu próprio histórico musical, dá notas aos álbuns que ouviu e acompanha seus rankings e avaliações. O nome representa a ideia central: **RANK + UP**, colocar os seus favoritos no topo.
